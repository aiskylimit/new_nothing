OFFLINE ASSET PREPARATION FOR THE SDXL Q3/DSPO PIPELINE
=======================================================

The training server must never download anything. Run this section on an
INTERNET-CONNECTED Linux x86_64 machine that matches the server's Python 3.10
and glibc, then copy the project plus offline_assets/ to the server.

1. Create the layout
--------------------

cd <project_dir>
mkdir -p offline_assets/{bin,wheelhouse,models,data/pickapic_v2_full,eval_sources,reward_models/open_clip,reward_models/HPSv2}

Install uv on the Internet machine if needed, then preserve its executable:

curl -LsSf https://astral.sh/uv/install.sh | sh
cp "$(command -v uv)" offline_assets/bin/uv
chmod +x offline_assets/bin/uv

2. Build the Linux wheelhouse
-----------------------------

Use pip only as a download/build frontend on the Internet machine. The offline
server installs and manages the environment with uv.

python3.10 -m venv .asset-builder
. .asset-builder/bin/activate
python -m pip install -U pip wheel build uv huggingface_hub open_clip_torch ImageReward pyarrow
python -m pip download --dest offline_assets/wheelhouse \
  --extra-index-url https://download.pytorch.org/whl/cu128 \
  -r requirements-offline-b200.txt

# ImageReward imports OpenAI CLIP. Build its wheel once; no git/network is used later.
git clone --depth 1 https://github.com/openai/CLIP.git .asset-builder/openai-clip
uv build --wheel --out-dir offline_assets/wheelhouse .asset-builder/openai-clip

Check that wheelhouse includes torch/torchvision cu128, diffusers,
transformers, datasets, hpsv2, image-reward and clip wheels. Do not build the
wheelhouse on Windows: Windows wheels cannot be installed on the Linux server.

3. Download SDXL and reward models from Hugging Face
----------------------------------------------------

Run this Python block while logged in to Hugging Face if your account requires
accepting the SDXL license:

python - <<'PY'
from huggingface_hub import snapshot_download, hf_hub_download
from pathlib import Path
import shutil

root = Path("offline_assets")
snapshot_download(
    "stabilityai/stable-diffusion-xl-base-1.0",
    local_dir=root / "models/stable-diffusion-xl-base-1.0",
    allow_patterns=[
        "model_index.json", "scheduler/*", "tokenizer/*", "tokenizer_2/*",
        "text_encoder/config.json", "text_encoder/model.fp16.safetensors",
        "text_encoder_2/config.json", "text_encoder_2/model.fp16.safetensors",
        "unet/config.json", "unet/diffusion_pytorch_model.fp16.safetensors",
    ],
    local_dir_use_symlinks=False,
)
snapshot_download(
    "madebyollin/sdxl-vae-fp16-fix",
    local_dir=root / "models/sdxl-vae-fp16-fix",
    allow_patterns=["config.json", "diffusion_pytorch_model.safetensors"],
    local_dir_use_symlinks=False,
)
snapshot_download(
    "laion/CLIP-ViT-H-14-laion2B-s32B-b79K",
    local_dir=root / "reward_models/CLIP-ViT-H-14-laion2B-s32B-b79K",
    local_dir_use_symlinks=False,
)
snapshot_download(
    "yuvalkirstain/PickScore_v1",
    local_dir=root / "reward_models/PickScore_v1",
    local_dir_use_symlinks=False,
)
snapshot_download(
    "bert-base-uncased",
    local_dir=root / "reward_models/bert-base-uncased",
    local_dir_use_symlinks=False,
)

def copy_hf(repo, filename, destination, repo_type="model"):
    source = hf_hub_download(repo, filename, repo_type=repo_type)
    destination = root / destination
    destination.parent.mkdir(parents=True, exist_ok=True)
    shutil.copy2(source, destination)

copy_hf("xswu/HPSv2", "HPS_v2.1_compressed.pt", "reward_models/HPSv2/HPS_v2.1_compressed.pt")
copy_hf("trl-lib/ddpo-aesthetic-predictor", "aesthetic-model.pth", "reward_models/ddpo-aesthetic-predictor/aesthetic-model.pth")
copy_hf("liuhuohuo2/pick-a-pic-v2", "data/test_unique-00000-of-00001-ecef20a3469ae6e6.parquet", "eval_sources/pickapic_test.parquet", "dataset")
copy_hf("nateraw/parti-prompts", "PartiPrompts.tsv", "eval_sources/PartiPrompts.tsv", "dataset")
copy_hf("ymhao/HPDv2", "test.json", "eval_sources/hpdv2_test.json", "dataset")

# Training code loads the standard Diffusers filename. These relative links
# reuse the downloaded FP16 tensors without storing duplicate weights.
model = root / "models/stable-diffusion-xl-base-1.0"
for component, stem in (("unet", "diffusion_pytorch_model"), ("text_encoder", "model"), ("text_encoder_2", "model")):
    source = model / component / f"{stem}.fp16.safetensors"
    target = model / component / f"{stem}.safetensors"
    if not target.exists():
        target.symlink_to(source.name)
PY

Download the OpenCLIP ViT-L/14 weight into the exact local filename:

python - <<'PY'
from pathlib import Path
import shutil, open_clip
cfg = open_clip.get_pretrained_cfg("ViT-L-14", "openai")
source = open_clip.download_pretrained(cfg, cache_dir=".asset-builder/open_clip")
target = Path("offline_assets/reward_models/open_clip/ViT-L-14-openai.pt")
target.parent.mkdir(parents=True, exist_ok=True)
shutil.copy2(source, target)
PY

Prepare ImageReward in the same directory layout its loader expects:

python - <<'PY'
import ImageReward as RM
RM.load("ImageReward-v1.0", device="cpu", download_root="offline_assets/reward_models/ImageReward")
PY

Fetch the tokenizer vocabulary required by hpsv2 1.2.0:

curl -L --fail -o offline_assets/reward_models/HPSv2/bpe_simple_vocab_16e6.txt.gz \
  https://raw.githubusercontent.com/tgxs002/HPSv2/master/hpsv2/src/open_clip/bpe_simple_vocab_16e6.txt.gz

4. Download/materialize the complete Pick-a-Pic v2 training set
----------------------------------------------------------------

Download every parquet shard. This is intentionally done before training so
the offline loader never streams from the Hub:

python - <<'PY'
from huggingface_hub import snapshot_download
snapshot_download(
    "liuhuohuo2/pick-a-pic-v2",
    repo_type="dataset",
    allow_patterns=["data/*.parquet"],
    local_dir="offline_assets/data/pickapic_v2_full",
    local_dir_use_symlinks=False,
)
PY

Flatten the parquet files with a same-filesystem move (not a copy) because the
runtime loader resolves manifest entries by basename, then create the exact
binary-preference manifest:

find offline_assets/data/pickapic_v2_full/data -type f -name '*.parquet' \
  -exec mv -n {} offline_assets/data/pickapic_v2_full/ \;
python hessian/prepare_binary_local_manifest.py \
  --data-dir offline_assets/data/pickapic_v2_full \
  --output offline_assets/data/pickapic_v2_full/manifest-full851k.json \
  --target-rows 851293 --workers 16

Do not delete the parquet files referenced by manifest-full851k.json. The asset
checker verifies every one before training starts.

5. Final layout to copy to the offline server
----------------------------------------------

<project_dir>/
  project_command.sh
  env.sh
  download.txt
  requirements-offline-b200.txt
  train.py, ratio_diffusion.py, hessian/, ...
  offline_assets/
    bin/uv
    wheelhouse/*.whl
    models/stable-diffusion-xl-base-1.0/...
    models/sdxl-vae-fp16-fix/...
    data/pickapic_v2_full/*.parquet
    data/pickapic_v2_full/manifest-full851k.json
    eval_sources/{pickapic_test.parquet,PartiPrompts.tsv,hpdv2_test.json}
    reward_models/...

Copy without dereferencing anything outside this tree; snapshot_download above
was instructed to materialize actual files. A typical transfer is:

rsync -a --info=progress2 <project_dir>/ user@offline-server:<destination>/

6. The one and only offline-server command
--------------------------------------------

cd <destination>/<project_dir>
bash project_command.sh

The script sets HF/Transformers/Datasets/Diffusers and WandB to offline mode,
validates all assets, creates the uv environment from wheelhouse, launches
Accelerate DDP on GPU 0-7, evaluates immediately after successful training,
and writes results/summary.json. It never pushes or uploads artifacts.

For the Hessian 2xA100 pilot only (maintainer validation, not the B200 run), the
same entrypoint is used with environment overrides:

PIPELINE_MODE=pilot GPU_IDS=2,3 NUM_GPUS=2 TARGET_GPU_FAMILY=A100 \
OFFLINE_EVAL_LIMIT=2 bash project_command.sh
